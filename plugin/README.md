# Antigravity Core Fixes plugin

This is the update-safe runtime edition. It is installed under
`~/.gemini/config/plugins/antigravity-core-fixes` and loaded into the current
official Antigravity application by the lightweight **Antigravity Core Fixes**
launcher. The official application bundle and `app.asar` are never modified.

Always open **Antigravity Core Fixes.app** instead of opening the official app
directly. Reinstalling or updating the official app does not overwrite this
plugin.
